# VitePress Markdown 格式参考

## 标题

```markdown
# 一级标题（页面标题）
## 二级标题（章节）
### 三级标题（小节）
#### 四级标题（子项）
```

## 列表

### 无序列表

- 项目一
- 项目二
  - 子项目 A
  - 子项目 B
- 项目三

### 有序列表

1. 第一步

### 任务列表

- [x] 已完成任务
- [ ] 未完成任务

## 代码块

```python
def hello(name):
    print(f"Hello, {name}!")
    return name
```

**带行号高亮**

```python {1,3-4}
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

## Mermaid 流程图

```mermaid
flowchart LR
    A[输入数据] --> B{处理?}
    B -->|是| C[输出结果]
    B -->|否| D[重新处理]
```

## Mermaid 时序图

```mermaid
sequenceDiagram
    participant A as 用户
    participant B as 服务端
    participant C as 数据库
    A->>B: 请求数据
    B->>C: 查询数据
    C->>B: 返回数据
    B->>A: 返回结果
```
