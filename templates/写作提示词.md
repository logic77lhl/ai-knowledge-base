# 写作提示词

把以下内容发给 AI（如 ChatGPT、DeepSeek、Qwen）来生成文档内容：

---

## 提示词模板

```
请用中文写一篇 AI 科普文章，主题是"【替换为你的主题】"。

## 要求

1. 使用 Markdown 格式，适配 VitePress 静态站点
2. 面向初学者，语言通俗易懂，避免过于学术化
3. 文章结构清晰，包含以下内容：
   - 概述（一句话总结）
   - 核心概念解释
   - 工作原理（可用 mermaid 流程图）
   - 常见应用场景（列表形式）
   - 技术演进/学习路线（表格形式）
   - 常见问题（Q&A 形式）
   - 总结
4. 适当使用代码块、表格、列表等 Markdown 语法
5. 字数控制在 2000-3000 字以内

## 示例框架

```markdown
# 文章标题

## 概述

> 一句话总结

## 一、核心概念

### 概念一

### 概念二

## 二、工作原理

## 三、应用场景

## 四、技术演进

| 阶段 | 内容 |
|:---:|:---:|

## 五、总结

---
```

请开始生成。
```

## 使用说明

1. 复制上方提示词模板
2. 将 `【替换为你的主题】` 改成你要写的主题
3. 发给 AI 生成内容
4. 将生成的内容复制到 `docs/` 目录下的 `.md` 文件中
5. 本地预览确认无误后 push 到 GitHub

## VitePress 支持的扩展语法

- 代码块语言标注：\`\`\`python、\`\`\`bash、\`\`\`yaml 等
- 自定义容器：::: tip / ::: warning / ::: danger
- 表格
- 任务列表：- [ ] 未完成 / - [x] 已完成
- 脚注
- 徽章：Badge
- 流程图：\`\`\`mermaid
- 代码组：CodeGroup
